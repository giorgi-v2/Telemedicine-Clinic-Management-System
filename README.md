# ტელემედიცინისა და კლინიკის მართვის პორტალი

## პროექტის მიმოხილვა

MediCare არის ტელემედიცინის პორტალის დემო ვებაპლიკაცია. პაციენტს ერთ სივრცეში შეუძლია მოძებნოს ექიმი, დაჯავშნოს ვიზიტი და ნახოს თავისი სამედიცინო ისტორია. ექიმის ბარათიდან ასევე იხსნება სადემონსტრაციო კონსულტაციის ჩატი.

- **ექიმების დირექტორია** — ექიმის ძიება სახელით და გაფილტვრა სპეციალობის მიხედვით.
- **ვიზიტების დაჯავშნა** — კალენდარში თარიღისა და ხელმისაწვდომი დროის არჩევა. დადასტურებული ჯავშნები ჩანს „ჩემი ვიზიტების“ გვერდზე და ინახება ბრაუზერის `localStorage`-ში.
- **პაციენტის ბარათი** — სამედიცინო ისტორიისა და დანიშნულებების ნახვა და რედაქტირება, ასევე დაგეგმილი ვიზიტების ნახვა.
- **ონლაინ კონსულტაციის ჩატი** — ტექსტური შეტყობინებების გაცვლის სიმულაცია პაციენტისა და ექიმის როლებით.

ეთო გუგეშაშვილი | ვიზიტების დაჯავშნა, კალენდარი და დროის სლოტები |

გიორგი დავითაშვილი | ონლაინ კონსულტაციის ჩატი |

## ტექნოლოგიური სტეკი

- **ძირითადი ტექნოლოგიები** — React, TypeScript და Vite.
- **სტილები** — Tailwind CSS და Sass/SCSS Modules.
- **მდგომარეობა და ნავიგაცია** — React Hooks, Redux Toolkit და React Router 7.
- **ფორმები და ვალიდაცია** — Formik და Yup ვიზიტის დაჯავშნის ფორმისთვის.
- **მონაცემები** — Fetch API კითხულობს სატესტო JSON ფაილებს `public/data` საქაღალდიდან.
- **სამუშაო ინსტრუმენტები** — Git და ESLint.

## პროექტის ლოკალურად გაშვების ინსტრუქცია

საჭიროა Node.js 22.13+ (22.x) ან 24+, ასევე npm.

1. ჩამოტვირთეთ ან დააკლონირეთ რეპოზიტორია და გახსენით პროექტის ძირითადი საქაღალდე.
2. დააინსტალირეთ დამოკიდებულებები და გაუშვით პროექტი.

   ```bash
   npm install
   npm run dev
   ```

3. ბრაუზერში გახსენით მისამართი, რომელსაც Vite ტერმინალში აჩვენებს.
4. საბოლოო ვერსიის ასაწყობად გაუშვით შემდეგი ბრძანება. შედეგი შეიქმნება `dist` საქაღალდეში.

   ```bash
   npm run build
   ```
