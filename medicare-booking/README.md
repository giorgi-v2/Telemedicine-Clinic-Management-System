# MediCare — Telemedicine & Clinic Management System

## პროექტის მიმოხილვა

MediCare არის React-ზე შექმნილი კლინიკის მართვის სასწავლო ვებაპლიკაცია, რომელიც მომხმარებელს ექიმთან ვიზიტის ონლაინ დაჯავშნის საშუალებას აძლევს.

## გუნდის წევრები და როლები

**გუნდი №:** [ჩაწერე ნომერი]

- **ელენე დევაძე:** ექიმების დირექტორია და ფილტრაცია.
- **ეთო გუგეშაშვილი:** ვიზიტების ონლაინ დაჯავშნის სისტემა.
- **სანდრო გულორდავა:** პაციენტის სამედიცინო ბარათი და ისტორია.
- **გიორგი დავითაშვილი:** ონლაინ ჩატი და ოპტიმიზაცია.

## ჩემი ინდივიდუალური ნაწილი — სტუდენტი 2

შექმნილია ვიზიტების დაჯავშნის ინტერაქტიული სისტემა, რომელიც მოიცავს კალენდარს, თავისუფალი საათების არჩევას, Formik + Yup ვალიდაციას, ჯავშნის დადასტურებასა და localStorage-ში შენახვას.

**კომპონენტები:** BookingModal, BookingForm, Calendar, TimeSlotPicker, BookingSuccess.

**Custom Hook:** useBookingForm.

## ტექნოლოგიები

- **Core:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, Sass/SCSS
- **Forms:** Formik, Yup
- **Hooks:** useState, useEffect, useMemo, useCallback
- **Data:** Fetch API, JSON, localStorage
- **Tools:** Git, GitHub, ESLint, Lighthouse, Chrome DevTools

გუნდური ვერსიის ტექნოლოგიურ მოთხოვნებში ასევე შედის Redux Toolkit და React Router.

## პროექტის გაშვება

```bash
git clone <repository-url>

npm run dev
```
