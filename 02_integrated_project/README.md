# ტელემედიცინისა და კლინიკის მართვის პორტალი

## პროექტის მიმოხილვა
პროექტი წარმოადგენს თანამედროვე მოდულურ რესპონსიულ ვებ-აპლიკაციას ტელემედიცინის სფეროსთვის, რომელიც აერთიანებს ექიმების დირექტორიას, ონლაინ ჯავშნებს, პაციენტის ბარათებს და ინტერაქტიულ ჩატს.

---

## გუნდის წევრები და როლების გადანაწილება
* **გუნდის ნომერი:** გუნდი №1
* **სტუდენტი 1:** ელენე დევაძე — *როლი:* ექიმების დირექტორია, API ფეჩინგი და ფილტრაცია
* **სტუდენტი 2:** ეთო — *როლი:* ვიზიტის დაჯავშნის მოდალი და ფორმა
* **სტუდენტი 3:** სანდრო — *როლი:* პაციენტის ბარათი, ისტორია და Redux Toolkit
* **სტუდენტი 4:** გიორგი — *როლი:* სადემონსტრაციო ჩატი, დებაგინგი და წარმადობა

---

## ტექნოლოგიური სტეკი (Tech Stack)
* **Core:** React (Vite), TypeScript
* **Styling:** Tailwind CSS, Sass/SCSS
* **Data Fetching:** Fetch API, Mock JSON (`public/data/doctors.json`)
* **Tools:** Git, GitHub, Chrome DevTools

---

## პროექტის ლოკალურად გაშვების ინსტრუქცია
1. **რეპოზიტორიის კლონირება:**
   ```bash
   git clone https://github.com/your-username/clinic-portal.git
   cd clinic-portal
   ```
2. **დამოკიდებულებების (Dependencies) ინსტალაცია:**
   ```bash
   npm install
   ```
3. **პროექტის გაშვება დეველოპმენტ რეჟიმში:**
   ```bash
   npm run dev
   ```
4. **პროექტის ბილდი (Build):**
   ```bash
   npm run build
   ```
